# Models of the Atom: Narration Script (draft for approval)

**Audience:** 10th grader who finds reading hard. The voice does the teaching. On-screen text is short labels only (6 words max).
**Pace:** about 130 words per minute. Short pause between scenes.
**Big idea:** Each model made a prediction. An experiment tested it. The result didn't fit, so scientists updated the model.

How to read this:
- Each row is one narration sentence. Each sentence is 12 words or fewer, and each row becomes one caption.
- "On screen" says what the viewer sees while that line is spoken.
- **Two videos.** The full script runs about 7 minutes, so it is split into Part 1 (Scenes 1–3) and Part 2 (Scenes 4–7). Each part stays under 4½ minutes. Every line is kept.
- ✂ marks lines that can be cut if a part runs long once the real voice is timed. Right now, all of them are in.
- New lines added for the split are marked **(new)**.
- The timeline bar across the top (1803 → 1926) always lights up the current model.
- Every model change uses the same steps: THE MODEL → WHAT IT PREDICTS → THE EXPERIMENT → WHAT REALLY HAPPENED → NEW MODEL.
- "Prediction" and "Result" cards always appear side by side.

## Notes

- **Pronunciations for the voice:** Leucippus (loo-SIP-us), Democritus (deh-MOK-rih-tus), Lavoisier (lah-vwah-zee-AY), Proust (proost), de Broglie (deh BROY), Schrödinger (SHROH-ding-er), Heisenberg (HY-zen-berg), Geiger (GY-ger).
- **Quote:** Rutherford's full quote (the "15-inch shell") is too long for a 12-word sentence. Lines 15–16 of Scene 4 paraphrase it ("said it was like"). They do not present it as an exact quote.
- **Accuracy guardrails, checked:**
  - Thomson's "pudding" is spread-out positive charge. It is never called protons.
  - The Nuclear Model shows loose, crossing electron paths with no rings. Rings first appear with Bohr.
  - The cathode ray goes from the cathode (−) to the anode (+). Alpha particles are positive (yellow, "+").
  - The gold foil scene doesn't claim to find protons or neutrons. Those appear only in the "1932" side note (Chadwick: neutron).
  - Orbitals are "places an electron is likely to be," never paths.
  - All dates are exactly as given.
